Online Trading System

The Online Trading System is a web-based application designed to facilitate the buying and selling of stocks through a user-friendly interface. The system allows users to create accounts, manage their portfolios, monitor stock prices, and execute trading transactions in a secure and efficient manner.

This project was developed to understand the fundamentals of financial trading platforms, database management, user authentication, and full-stack web application development. The system provides a streamlined experience for users to track investments and manage trading activities in real time.

Features
* User Registration and Login Authentication
* Stock Buying and Selling Functionality
* Portfolio Management
* Transaction History Tracking
* Real-Time Stock Information Display
* Secure User Data Management
* Responsive and User-Friendly Interface

Technologies Used
* HTML5
* CSS3
* JavaScript
* React.js
* Node.js
* Express.js
* MySQL / MongoDB

What I Learned
Through this project, I gained practical experience in developing a full-stack web application, implementing user authentication, managing databases, handling API integration, and designing responsive user interfaces. It also improved my understanding of financial trading workflows and secure transaction management.
